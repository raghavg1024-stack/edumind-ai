# Smart Classroom: implementation, operation, and verification

EduMind keeps its existing Next.js interface, bearer-token authentication, Gemini tutor, and pgvector chunks table. Classroom adds course-linked lectures, private MP4 storage, the official YouTube player, searchable timed transcripts, clickable video citations, quiz revision links, notes, bookmarks, and saved playback position.

## Current local services

- EduMind: http://localhost:3000
- Private speech API: http://127.0.0.1:8787
- Separate Node worker: polls durable Supabase video_jobs

These services run in hidden background processes. They must be started again after restarting the computer. The helper is `scripts/start-classroom.ps1`; logs and process IDs are in the thread's work folder. It expects the existing Python environment in that work folder, or a `-PythonPath` argument pointing to your own environment. Do not run multiple worker copies unnecessarily.

## Architecture

Authenticated browser → signed upload to private lecture-videos bucket → course/topic lecture record → durable queued job → worker claims a lease → FFprobe validates duration/audio/video → FFmpeg extracts mono 16 kHz PCM audio → prerecorded speech API recognizes actual audio and supplies word-aligned segment times → chunks retain enclosing source times → Gemini embeddings → atomic database publication → existing RAG tutor/quiz/mastery/plan.

Short-lived web routes never perform video transcription. Processing survives browser navigation. Expired worker leases can be reclaimed up to three attempts; explicit failures show their reason and allow retry. Only a worker holding the current lease can publish. A failed replacement keeps the last completed transcript rather than publishing partial data.

## Speech provider

The local setup uses faster-whisper with an English tiny.en model on CPU. The API returns sentence segments assembled from recognized word timestamps. It does not use the lecture title or an initial prompt as transcript content. No paid speech key is needed. The bundled known-speech sample is synthetic narration generated by Windows speech synthesis; its original captions are authored from that narration, while automatic-transcription tests recognize the audio independently.

Whisper recognition can miss terms and approximate boundaries; check the transcript before relying on it. The initial demo model is English only. Set WHISPER_MODEL to a suitable multilingual/larger model for other languages or stronger accuracy, and download it before your demo. CPU speed and memory depend on the model and lecture length.

Web Speech supports microphone/audio-track recognition in limited browsers, but does not supply the word-aligned background processing contract required here. It is not used to manufacture a lecture transcript.

Alternate providers: set STT_PROVIDER=deepgram and DEEPGRAM_API_KEY, or STT_PROVIDER=http and STT_API_URL. A custom HTTP provider receives multipart audio `file`, optional `model`, and `response_format=verbose_json`; it must return `segments: [{start, end, text}]` in seconds. STT_API_KEY is sent as Bearer authorization if supplied. Remote endpoints must use HTTPS.

## Environment settings

- NEXT_PUBLIC_SUPABASE_URL and NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY: public browser connection settings. Never put a secret key here.
- GEMINI_API_KEY: server-only embedding/tutor/quiz key.
- GEMINI_MODEL: gemini-3.8-flash was verified; the account's old gemini-2.5-flash generation model was unavailable to new users. Generation uses bounded timeouts, transient retries, and low thinking for Gemini 3.
- GEMINI_EMBEDDING_MODEL: gemini-embedding-001, normalized 768-dimensional vectors. Changing models requires reindexing all materials.
- VIDEO_WORKER_ENABLED=true: web UI may enqueue indexing.
- VIDEO_TRANSCRIPTION_ENABLED=true: web UI may enqueue prerecorded transcription once the speech API is running.
- VIDEO_WORKER_SUPABASE_KEY: server-only worker key with privileged database/storage access. Never ship it to browsers or include .env.local in a ZIP.
- STT_PROVIDER=http and STT_API_URL=http://127.0.0.1:8787/transcribe: local speech API.
- FFMPEG_PATH / FFPROBE_PATH: optional executable paths; defaults use PATH.

## Database

The hosted project received `edumind_smart_classroom_initial` and a covering-FK-index migration. Desired schema files are `edumind.sql`, `smart_classroom.sql`, and `video_jobs.sql`, in that order. Do not rerun the initial scripts against an already configured project. Future changes should use the configured declarative schema/migration workflow.

Added: courses, lectures, lecture_transcripts, lecture_segments, lecture_bookmarks, video_progress, video_jobs. Every table has RLS; composite owner foreign keys prevent linking a resource to another learner's lecture or course. Videos are in a private 50 MB bucket. Upload permission requires an owned lecture awaiting upload. Playback uses expiring signed URLs.

The existing table is `chunks`, not resource_chunks. A `security_invoker` resource_chunks view provides compatibility with the challenge name while retaining one vector knowledge base. Lecture chunks carry lecture_id, start_seconds, and end_seconds. Uploaded transcripts can be retrieved using keyword matching before vector indexing. Indexed transcripts participate in the same cosine retrieval as PDFs and PPTX. Quiz citation snapshots preserve revision timestamps even if a transcript is reindexed later.

## Use

1. Sign in or create your own student account via the profile. Confirm email if Supabase requests it.
2. Open Classroom, add an H.264/AAC MP4 with a lecture title, course, and topic.
3. Upload a permitted VTT/SRT or timed segment JSON for immediate Phase 1 captions, search, and timestamp citations, or select Transcribe audio for automatic processing.
4. Watch the queued → processing → ready state. Search the transcript and click a cue to seek.
5. Ask the tutor a question from the lecture. Click a video source citation to open the exact moment.
6. Practice the lecture topic; after an incorrect answer, click Revisit source. Scores update the existing mastery and study-plan rules.
7. Save a note at the current moment; click its timestamp to revisit. Compare lecture excerpts with a textbook/slide passage or ask the tutor to compare sources.

YouTube uses only the official embed API. No caption scraping or unauthorized video downloads are performed. Upload a transcript you can legitimately use when captions are unavailable. Embedding can be disabled by a video owner; the UI reports playback errors. This mode is implemented, but external YouTube playback has not been validated for a specific video/region.

## Reproduce tests

```
npm test
npm run lint
npx tsc --noEmit
npm run build
npm run verify:video:live
npm run verify:classroom:cloud
```

The cloud verifier creates temporary test-only students, uploads the bundled sample, checks private playback and cross-student isolation, uploads captions, invokes the real background job, checks recognized concepts and timestamp alignment, asks the real Gemini tutor, creates a quiz, grades wrong answers, verifies revision links/mastery/notes, then removes its test accounts and video. It never emails a real person. Results are in docs/cloud-verification.json. Live model checks are in docs/live-verification.json. Read the result statuses before claiming a test passed.

## Deploying workers

The web UI/API can run on Next.js hosting. Deploy `worker/Dockerfile` to a long-lived service with FFmpeg and persistent environment settings, plus `worker/speech.Dockerfile` for the speech API if using local Whisper. Set an STT_API_KEY before binding the speech API outside localhost (startup enforces this); use a private network and HTTPS for remote access. Keep a persistent model-cache volume and prewarm the model. Docker deployment files are provided but have not been built or deployed in this Windows environment.

For a manual non-Docker worker: install Node dependencies, FFmpeg and Python 3.11; create a Python virtual environment and install worker/speech-requirements.txt; run worker/speech_api.py in one process and `npm run worker:video` in another. Python speech model and virtual environment are not included in the source ZIP.

## MVP limits

Uploads: 50 MB and up to four hours. Automatic recognition: up to one hour / 125 MB extracted audio. Playback support requires H.264/AAC-compatible MP4. Uploads use signed standard uploads, not resumable TUS; long or interrupted uploads may need retry. A resume-upload endpoint exists, but there is no dedicated upload-retry picker yet. No video deletion interface. Local preview videos and notes are session-only.

Mastery remains cumulative topic practice accuracy, not an educational diagnosis or validated knowledge model. Multiple lectures share a topic's score. Citations identify real resources/time intervals, but generation and speech recognition still need human review. Signed video links expire after four hours. The app does not automatically restore its live view after a reload; sign in again to reopen saved data.

No production load test, exhaustive accessibility audit, distributed cost/rate limits, or Docker deployment verification was performed. Automatic transcription is local to this computer until you deploy the compatible worker services.


### Provider outage behavior

If Gemini returns a transient busy/quota response after bounded retries, tutoring returns exact retrieved passages with a source-only label. Practice can return a source-check quiz made from real source statements, labeled as such. Those questions preserve lecture citation metadata and update ordinary practice accuracy, but do not claim adaptive AI complexity. Cloud verification marks these modes degraded, not passed AI generation. The full video pipeline can still be demonstrated during a provider outage.

Use `npm run classroom:start` for the persistent Node service supervisor; `npm run verify:classroom:stack` starts an isolated test web server on port 3001 and its own worker, then stops only those test processes. The private speech API on port 8787 must already be running.
